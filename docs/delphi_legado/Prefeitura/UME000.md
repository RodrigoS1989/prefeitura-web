# UME000

Documentação para agentes de IA. Descreve o código; não substitui o fonte na hora de editar.

## Propósito

Menu principal da Prefeitura. Caption: "Menu de Opções". Classe `TME000`. Criado no `Prefeitura.dpr` quando o sistema não está em modo robô.

## Contexto de uso

Ponto de entrada com interface. O item de produção e-SUS deste menu escolhe PM1047 ou PM134.

## Superfície pública

O método que abria a produção e-SUS não foi nomeado no diff. Saiu `procedure VerificaGestorEsus`.

## Fluxo principal

1. O operador aciona a produção e-SUS no menu.
2. Se `conParametroSaude.GetParametro.GetUsaValidacaoSqlEsus` for verdadeiro, abre `TFormEsusProducao` modal.
3. Senão, abre `TPM134` (PM134) modal.
4. `VerificaGestorEsus` não liga mais o `TimerCorreio` a partir de `tb_EsusGestores`.

## Regras de negócio

- A nova geração de fichas só entra no menu com `fl_UsaValidacaoSqlEsus` carregado no parâmetro (`GetUsaValidacaoSqlEsus`).
- Gestor e-SUS deixou de ser o critério para ativar o timer do correio.

## Dados

`VerificaGestorEsus` usava `Select cd_Gestor From tb_EsusGestores Where cd_Gestor = <operador> and dt_Exclusao is null`. Essa consulta saiu.

## Interface

- `ME000` — caption "Menu de Opções".
- O item de menu da produção não foi nomeado no diff. O form aberto é PM1047 ou PM134.

## Dependências

`Prefeitura.View.Form.EsusProducao`, `conParametroSaude`, `TPM134`.

## Cuidados ao alterar

Fonte Windows-1252. A unit tem cerca de 7302 linhas. O mesmo `if` do parâmetro aparece duas vezes no diff; os dois pontos de menu precisam continuar iguais.

## Alteração na revisão

Troca de PM134 por `TFormEsusProducao` quando o parâmetro está ligado, e remoção de `VerificaGestorEsus`.

## Limites

Não foi lido o nome do procedimento de menu nem o caption do item. O segundo bloco idêntico do diff não foi situado (pode ser outro item ou o mesmo método em outro ramo).
