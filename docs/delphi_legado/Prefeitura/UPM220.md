# UPM220

Documentação para agentes de IA. Descreve o código; não substitui o fonte na hora de editar.

## Propósito

Recepção de exames. Caption: "PM220 - Recepção de Exames". Classe `TPM220`.

## Contexto de uso

Aberto pela recepção. O chamador não foi lido. Depois de gravar a ficha de procedimentos ligada ao exame, envia a FAP para a API.

## Superfície pública

Não houve método novo nomeado no diff. Entrou `Shared.Esus` e a chamada `EnviarFichaApi`.

## Fluxo principal

1. A exclusão de exame, quando a tela de origem é `PM219`, continua bloqueada se `cdsExamesfl_Avaliado = 'S'`.
2. Se o exame tem imagem (`BuscaExameImagem`), pede confirmação antes de excluir os arquivos junto.
3. `cdsExames.Delete` remove o item.
4. Noutro ponto, após localizar `cd_FAP`, chama `TEsus.NovoControlador.EnviarFichaApi` com `TEsusTipoFicha.etfFAP`.

## Regras de negócio

- Exame já avaliado não pode ser excluído quando `strTela = 'PM219'`.
- Exame com imagem só é excluído se o usuário confirmar.
- A ficha de procedimentos encontrada é enviada à API e-SUS.
